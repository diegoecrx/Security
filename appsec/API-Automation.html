1HTTP & REST fundamentals

An HTTP API exposes resources at URLs (endpoints). A client sends a request (method, URL, headers, optional query parameters and body); the server returns a response (status code, headers, body — typically JSON).

2Requests

The requests library (pip install requests) covers the common cases. Always set a timeout; check the status.

import requests

# GET with query parameters and headers
resp = requests.get(
    "https://api.github.com/users/torvalds/repos",
    params={"per_page": 100, "sort": "updated"},
    headers={"Accept": "application/vnd.github+json"},
    timeout=10,
)
resp.raise_for_status()        # raise on 4xx/5xx
data = resp.json()             # parse JSON body

# POST with a JSON body
requests.post(url, json={"name": "item"}, timeout=10)   # json= sets body + Content-Type

For many requests to one API, use a session (requests.Session()) with shared headers — it reuses the connection and centralizes auth.

4JSON

JSON maps directly to Python types: object→dict, array→list, true/false/null→True/False/None.

import json

data = requests.get(url).json()       # response body → dict/list
data = json.loads(text)              # string → object
text = json.dumps(data, indent=2)     # object → string

value = data.get("key")             # None if absent (vs. data["key"] → KeyError)

Use .get() for fields that may be absent. loads/dumps operate on strings; load/dump operate on file objects.

6File handling

Use the with statement (auto-closes on exit, including on error) and specify encoding.

import json, csv
from pathlib import Path

# text: mode "w" overwrites, "a" appends
with open("report.txt", "w", encoding="utf-8") as f:
    f.write("line\n")

# JSON to a file (load/dump take a file object)
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2)

# CSV (opens in spreadsheet tools)
with open("out.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["name", "stars"])
    w.writeheader(); w.writerows(rows)

path = Path("output") / "out.csv"    # cross-platform path join

7Automation patterns

Pagination

APIs return results in pages. Iterate until an empty page:

items, page = [], 1
while True:
    batch = session.get(url, params={"per_page": 100, "page": page}, timeout=10).json()
    if not batch: break
    items.extend(batch); page += 1

Rate limiting & retry with backoff

import time
for attempt in range(3):
    resp = session.get(url, timeout=10)
    if resp.status_code not in (429, 403): break
    time.sleep(2 ** attempt)       # exponential backoff: 1s, 2s, 4s

Scheduling: cron (Linux/macOS), Task Scheduler (Windows), or a scheduled CI job (e.g. GitHub Actions). A robust script reads config from the environment, handles errors explicitly (timeout, status, missing fields), logs its actions, and is safe to re-run.

8Worked example: GitHub API

PropertyValue
Base URLhttps://api.github.com
AuthPersonal access token — Authorization: Bearer <token>

"""Fetch a user's repositories, filter by name, write CSV."""
import os, re, csv, time, sys, requests

TOKEN = os.environ.get("GITHUB_TOKEN")
if not TOKEN: sys.exit("Set GITHUB_TOKEN")
USER = "torvalds"

session = requests.Session()
session.headers.update({
    "Authorization": f"Bearer {TOKEN}",
    "Accept": "application/vnd.github+json",
    "X-GitHub-Api-Version": "2022-11-28",
})

def get_all_repos(user):
    repos, page = [], 1
    while True:
        url = f"https://api.github.com/users/{user}/repos"
        for attempt in range(3):
            r = session.get(url, params={"per_page": 100, "page": page}, timeout=10)
            if r.status_code != 403: break
            time.sleep(2 ** attempt)
        r.raise_for_status()
        batch = r.json()
        if not batch: break
        repos.extend(batch); page += 1
    return repos

rows = []
for repo in get_all_repos(USER):
    if re.search(r"(?i)linux|kernel", repo["name"]):
        rows.append({
            "name": repo["name"],
            "stars": repo["stargazers_count"],
            "language": repo.get("language") or "?",
            "url": repo["html_url"],
        })

with open("repos.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.DictWriter(f, fieldnames=["name", "stars", "language", "url"])
    w.writeheader(); w.writerows(rows)

The script applies every element above: environment-based auth, a session, paginated retrieval with backoff retry, JSON parsing with safe field access, a regex filter, and CSV output.

9Best practices

  • Read credentials from the environment or a secrets manager; never commit them.
  • Set a timeout on every request; check status (raise_for_status()).
  • Respect rate limits; retry transient failures with exponential backoff.
  • Paginate; do not assume a single response contains all results.
  • Use .get() for optional JSON fields; validate response shape against real data.
  • Test against a small sample before iterating over a full dataset.
  • Identify the client (User-Agent); observe the API's terms and documented limits.

11Terminology & references

Terminology

  • Endpoint — a specific API URL.
  • Method — HTTP verb (GET/POST/…).
  • Status code — server result code.
  • Query parameter — option after ? in the URL.
  • Pagination — retrieving results in pages.
  • Rate limit — cap on requests per period.
  • Backoff — increasing delay between retries.
  • Session — reusable client with shared state.
